# 가게온 PRO — 소상공인 매출·홍보 올인원

동네 가게 사장님을 위한 홍보 + 매출 관리 도구입니다. 파일 하나(`index.html`)로 동작하며, 설치나 서버가 필요 없습니다.

**바로 열기 → https://ssunwoochoi-create.github.io/gageon-studio/**

## 들어 있는 기능

1. **매장 프로필 & 업종 프리셋** — 한식·카페·미용·헬스·공방·자유 업종 프리셋, 여러 매장 저장·전환
2. **멀티채널 홍보글 생성** — 인스타그램·스레드·당근·네이버 플레이스 문구를 한 번에 생성 (API 키 없이 내장 엔진으로 동작, OpenAI/Gemini 키 선택 연결)
3. **카드뉴스 스튜디오** — 사진을 넣어 1080px PNG 카드뉴스 생성·저장
4. **주간 홍보 플래너** — 이번 주 7일치 홍보 일정 자동 배치
5. **리뷰 답글** — 리뷰 유형별 3가지 톤 답글 생성
6. **단골·매출 관리 (PRO)** — 객단가·결제 건수·단골 비중을 넣으면 월 추가 매출과 순이익(구독료 차감)을 실시간 계산. 12개월 누적 효과 표와 사장님께 보낼 요약 문장 복사. 배달 봉투·테이블 POP용 **단골 재방문 쿠폰 1080×1080 PNG** 즉시 생성(매장명·주소·전화 자동 반영, 4가지 디자인)
7. **요금제 · 도입 안내** — Starter 월 29,000원 / Pro 월 49,000원 / 세팅 대행 190,000원 안내와 **7일 무료 시범 운영 신청서**. 신청 내용은 카톡·문자로 보낼 수 있는 제안서 문구로 복사됩니다.

## 사용 방법

- 아이폰·안드로이드·PC 브라우저에서 위 주소를 열면 바로 실행됩니다.
- 입력한 매장 정보·신청서는 그 브라우저(localStorage)에만 저장되며 서버로 보내지 않습니다.
- AI 키를 연결하면 더 다양한 문구가 나오고, 키가 없어도 내장 엔진으로 모든 기능이 동작합니다.
- 링크를 사장님께 보낼 때는 카톡 미리보기(OG 이미지)까지 그대로 나옵니다.

## 영업할 때 쓰는 순서 (권장)

1. 매장 정보를 그 자리에서 입력 → **⑥ 단골·매출 관리**에서 객단가·일 결제 건수를 넣고 개선 목표(+10%) 선택
2. **계산 결과 복사하기** → 사장님께 카톡으로 전송 (지금 매출 → 개선 후 매출 → 구독료 빼고 남는 이익)
3. **단골 쿠폰 PNG 저장** → 그 자리에서 쿠폰 이미지 한 장 보여 주기
4. **요금제 · 도입 안내 → 7일 무료로 먼저 써보기** → 신청서 작성 → **도입 제안서 전체 복사**

## 파일

- `index.html` — 앱 전체(HTML/CSS/JS 단일 파일)
- `og-image.png` — 카톡·SNS 링크 미리보기 이미지 (1200×630)
