# 가게온 PRO — 소상공인 매출·홍보 올인원

동네 가게 사장님을 위한 홍보 + 매출 관리 도구입니다. 파일 하나(`index.html`)로 동작하며, 설치나 서버가 필요 없습니다.

**바로 열기 → https://gageon-pro.vercel.app/**

## 들어 있는 기능

1. **매장 프로필 & 업종 프리셋** — 한식·카페·미용·헬스·공방·자유 업종 프리셋, 여러 매장 저장·전환
2. **멀티채널 홍보글 생성** — 인스타그램·스레드·당근·네이버 플레이스 문구를 한 번에 생성 (API 키 없이 내장 엔진으로 동작, OpenAI/Gemini 키 선택 연결)
3. **카드뉴스 스튜디오** — 사진을 넣어 1080px PNG 카드뉴스 생성·저장
4. **주간 홍보 플래너** — 이번 주 7일치 홍보 일정 자동 배치
5. **리뷰 답글** — 리뷰 유형별 3가지 톤 답글 생성
6. **단골·매출 관리 (PRO)** — 객단가·결제 건수·단골 비중을 넣으면 월 추가 매출과 순이익(구독료 차감)을 실시간 계산. 12개월 누적 효과 표와 사장님께 보낼 요약 문장 복사. 배달 봉투·테이블 POP용 **단골 재방문 쿠폰 1080×1080 PNG** 즉시 생성(매장명·주소·전화 자동 반영, 4가지 디자인)
7. **플레이스·AI 상위노출 진단 (GEO)** — 네이버 스마트플레이스 5항목(50점) + AI 검색·GEO 5항목(50점) = 100점 진단. 항목별 미흡·보통·완료를 누르면 점수가 실시간 재계산되고, 감점 이유와 바로 실행할 개선안이 붙습니다. **개선 패키지 4종**(추천 키워드 5개 / 상세설명 초안 / 찾아오시는 길 / AI 추천용 Q&A 3문 3답) 복사, **진단 리포트 카톡용 복사**, 네이버 플레이스·ChatGPT·퍼플렉시티 **실제 검색 확인 링크** 제공. ※ 브라우저 단독 진단이며 네이버·AI 서버를 실시간으로 읽지 않습니다.
8. **요금제 · 도입 안내 (세팅 1회 + 월 관리 2단계)** — 1단계 **초기 세팅 대행 1회 190,000원**(스마트플레이스 정보·키워드 점검, 채널 프로필, 맞춤 프리셋, 첫 주 홍보글·카드뉴스 초안), 2단계 **월 관리 구독** Starter 월 29,000원(직접 운영 + 매달 진단 리포트) / Pro 월 49,000원(운영 대행 + 진단 코칭 + 매장 3곳). 첫 달 219,000원 / 239,000원, 다음 달부터 월 요금만. **7일 무료 시범 운영 신청서**와 카톡·문자로 보낼 제안서 문구 복사 포함.

## 사용 방법

- 아이폰·안드로이드·PC 브라우저에서 위 주소를 열면 바로 실행됩니다.
- 입력한 매장 정보·신청서는 그 브라우저(localStorage)에만 저장되며 서버로 보내지 않습니다.
- AI 키를 연결하면 더 다양한 문구가 나오고, 키가 없어도 내장 엔진으로 모든 기능이 동작합니다.
- 링크를 사장님께 보낼 때는 카톡 미리보기(OG 이미지)까지 그대로 나옵니다.

## 영업할 때 쓰는 순서 (권장)

1. 매장 정보를 그 자리에서 입력 → **⑦ 상위노출 진단**에서 상호·동네만 넣고 **진단 실행** → 사장님과 함께 항목 체크 → **진단 리포트 카톡용 복사**
2. **⑥ 단골·매출 관리**에서 객단가·일 결제 건수를 넣고 개선 목표(+10%) 선택
3. **계산 결과 복사하기** → 사장님께 카톡으로 전송 (지금 매출 → 개선 후 매출 → 구독료 빼고 남는 이익)
4. **단골 쿠폰 PNG 저장** → 그 자리에서 쿠폰 이미지 한 장 보여 주기
5. **요금제 · 도입 안내 → 7일 무료로 먼저 써보기** → 신청서 작성 → **도입 제안서 전체 복사**
